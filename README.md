# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: сайт фитнес-клуба для скалолазания (скалодрома) «Хват».

Это отдельная реализация предметной области через CSS-фреймворк Bootstrap 5.3 (подключён через CDN). Архитектура проекта повторяет проект КР №1 (`kr1-html-css-shop`): многостраничный сайт, единые шапка и подвал, данные в `js/products.js`, страница тренировки открывается как `product.html?id=N`.

## Структура проекта

- `index.html` — главная: баннер с акцией, преимущества, популярные направления, «Как начать», подбор тренировки;
- `catalog.html` — тренировки: сетка карточек, фильтры по возрасту и уровню, аккордеон с вопросами;
- `product.html` — страница тренировки (`?id=N`): описание, что взять с собой, расписание, цена, кнопка «Записаться», похожие тренировки;
- `trainers.html` — карточки тренеров, по клику модальное окно с биографией, достижениями и группами;
- `schedule.html` — расписание по дням недели, таблица абонементов, калькулятор стоимости;
- `about.html` — о клубе, миссия и планы, контакты, отзывы (слайдер), галерея с фильтром по зонам, FAQ;
- `order.html` — онлайн-запись: тренировка, дата, свободный слот, имя и телефон, окно подтверждения;
- `css/custom.css` — собственные стили (CSS-переменные, БЭМ-блоки);
- `js/theme.js` — применение сохранённой темы до отрисовки страницы;
- `js/products.js` — единый список тренировок и тренеров;
- `js/main.js` — тема, «Наверх», фильтр каталога, страница тренировки;
- `js/features.js` — калькулятор, окно тренера, галерея, подбор тренировки;
- `js/booking.js` — онлайн-запись;
- `images/` — SVG-иллюстрации тренировок и галереи, `preview.png` для Open Graph;
- `sitemap.xml`, `.gitignore`, `.gitattributes`, `README.md`.

## Как посмотреть проект

Склонировать репозиторий и открыть `index.html` в браузере (нужен интернет для Bootstrap и шрифтов с CDN). Сборка не нужна.

Что проверить: меню и мобильное меню (navbar), переключатель темы (выбор сохраняется), фильтры каталога, `product.html?id=3`, модальное окно тренера, калькулятор, слайдер отзывов, фильтр галереи, тест подбора, онлайн-запись.

## Используемые технологии

- HTML;

## Реализованные компоненты Bootstrap

- сетка: `container`, `row`, `col-*`, `g-*`;
- `navbar` с мобильным меню;
- `card` (тренировки, тренеры, преимущества, шаги);
- `btn` (варианты primary, outline, `btn-group`);
- `badge` (уровень, возраст, «Хит», «Новинка»);
- `alert` (акция, ошибки формы, пустой каталог, сообщения);
- формы: `form-control`, `form-select`, `input-group`, `form-check`;
- `modal` (тренер, подтверждение записи);
- `accordion` (FAQ), `nav-tabs` (страница тренировки), `carousel` (отзывы), `table`, `breadcrumb`, `progress`.

## Дополнительные функции

1. Тёмная и светлая тема (`data-bs-theme`, сохранение в `localStorage`).
2. Калькулятор стоимости: тип занятия, число посещений, аренда.
3. Раздел «Тренеры» с модальными окнами.
4. Отзывы-слайдер и галерея с фильтром по зонам.
5. Подбор тренировки: тест из 4 вопросов.
6. Онлайн-запись с выбором даты и свободного слота.
